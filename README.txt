roTV - instalare pe iPhone

Acesta este un prototip PWA cu linkuri către surse oficiale.
Nu retransmite canale și nu oferă acces gratuit la servicii cu plată.

Pentru instalare ca aplicație:
1. Publică fișierele acestui folder pe un hosting HTTPS static.
2. Deschide adresa HTTPS în Safari pe iPhone.
3. Apasă Share -> Add to Home Screen -> Add.
